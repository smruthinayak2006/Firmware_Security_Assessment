## Commands Learned

git init
Purpose:
Creates a new Git repository.

git status
Purpose:
Checks current project changes.

git add .
Purpose:
Stages modified files before saving.

git commit -m
Purpose:
Creates a saved checkpoint.

git remote
Purpose:
Connects local Git with GitHub.

git push
Purpose:
Uploads commits to GitHub.
